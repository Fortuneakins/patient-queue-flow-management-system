# Verification evidence folder

Place final evidence generated from the exact assessed release here.

Recommended files:

- `test-run.md` — date, environment, commit, test totals and results
- `performance.md` — p95 latency and Display Board latency measurements
- `accessibility.md` — Lighthouse score and keyboard results
- `compatibility.md` — exact browser versions tested
- `screenshots/` — representative UI evidence mapped to SCR-01…SCR-16
- `defects.md` — resolved defect evidence and regression references

Do not store real patient information, real credentials or other sensitive data here.
